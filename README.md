# Random Tools & Games

A modular home for small, experimental browser games and utilities.

## Games

### Oddworks

A character-driven systems puzzle set in a whimsical mechanical town. Observe a
living market, discover its rules, and combine specialists, scarce resources,
and physical contraptions to create your own solution.

Run the zero-dependency MVP locally:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/games/oddworks/`.
